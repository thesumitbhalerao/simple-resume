# HTML Resume

This project is a simple **Resume Web Page** created using **HTML5** as part of my daily practice during the **Python Full Stack Development** course at **The Kiran Academy**.

## 📌 Project Description

The objective of this project is to design a basic resume using only HTML. It demonstrates the use of common HTML elements to organize and display personal, educational, and professional information in a structured format.

## ✨ Features

- Personal information
- Career Objective section
- Educational qualifications
- Skills section
- Projects section
- Contact details
- Simple and clean HTML structure

## 🛠️ Technologies Used

- HTML5
- Visual Studio Code

## 📂 Project Structure

```
html-resume/
│── Aug5.html
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `Aug5.html` file in any web browser.

## 📚 Learning Outcomes

Through this project, I learned:

- Creating a structured HTML document
- Using headings, paragraphs, and formatting tags
- Organizing content into different sections
- Building a simple resume webpage using HTML
- Writing clean and readable HTML code

## 📸 Output

Open the `Aug5.html` file in your browser to view the resume webpage.
